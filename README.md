# Barttolo Reliquias

Mod en desarrollo para Minecraft Java 1.20.1 y Forge 47.4.10.

Cinco reliquias consumibles con mejoras permanentes por jugador. Cada tipo admite diez usos. La integración de campaña contempla una reliquia aleatoria por primera victoria en cada una de las 23 misiones y tres por la primera victoria válida del futuro jefe interdimensional.

El jefe no se implementa en este proyecto. No hay recetas ni venta con R-Coins.

Estado: preparación del proyecto y del entorno de compilación. Todavía no hay una versión instalable.
